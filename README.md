# For my gurl 💌

A little valentine site, live on GitHub Pages.

- **index.html**: an envelope she taps open, then the question. The No button runs away, the Yes button grows each time she tries No, and the cat gets sadder (and eventually cries). After enough tries, the No button gives up and turns into a Yes.
- **yes.html**: confetti, a love letter that types itself out, and a date picker.

## Customise it

Everything personal is in [`style/js/config.js`](style/js/config.js): her name, the No-button lines, the letter, the signature and the date ideas.
